# OB-Personal-Sync

OB-Personal-Sync is a personal configuration of the Google Drive Sync plugin for Obsidian, developed by Richard Xiong.

This configuration uses the owner's Google OAuth client to synchronize personal Obsidian notes, attachments, and selected configuration files between the owner's devices and Google Drive.

The application requests the `drive.file` permission to access files created by or explicitly authorized for this application.

This installation is intended solely for the owner's personal use. It does not offer a public synchronization service and is not affiliated with Google or the Obsidian developers.

This website provides application information only. It does not request or receive Obsidian notes, OAuth tokens, or client secrets.

[Read the Privacy Policy](privacy.html)

For questions, use the support email listed on this application's Google authorization screen.
